# Example Closed Module Demo

A [KernelSU](https://kernelsu.org) module that demonstrates the **closed-source** publishing
layout of [KernelSU Modules](https://modules.kernelsu.org): the source lives in one repository,
and every release is published to a separate **public** repository that only contains the module
metadata and the release ZIPs.

It installs nothing and does nothing on the device.

See [Closed-source modules](https://developers.kernelsu.org/docs/closed-source) in the developer
documentation for the full setup.
